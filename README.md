# Boss Print Go

Build a new mobile-first web app named BOSS PrintGo.

Tagline: Upload • Pay • Pickup

Tech: React, Vite, TypeScript, Tailwind CSS, Supabase-ready architecture.

Create a premium, modern, attractive blue-and-white UI with smooth animations, rounded cards, clean icons and responsive layouts.

Customer-facing app:

Single-page dashboard.

Header with BOSS PrintGo branding.

File Upload area.

Print Settings.

Customer Details.

Automatic Price Summary.

Payment section.

Order Tracking.

Admin:

Separate secure /admin route.

Modern sidebar dashboard layout.

Login page.

Support Tamil and English. Use simple navigation suitable for students.

Build UI and navigation only in this step. Use mock data for previews. Do not implement backend yet. Minimize credits.
